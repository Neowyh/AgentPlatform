## Quick Overview

### What is iDeer

iDeer is an enterprise-grade AI agent platform built on LangGraph, providing multi-model conversation, agent orchestration, and workflow automation capabilities. It supports private deployment and is suitable for enterprise intranet environments.

### Core Capabilities

| Capability | Description |
|------------|-------------|
| **Multi-model Chat** | Supports multiple LLM models with Flash/Thinking/Pro/Ultra reasoning modes |
| **Agent** | Create custom AI assistants with dedicated skills, tools, and system prompts |
| **Workflow** | Declarative graph DSL based on LangGraph for automating multi-step processes |
| **Skills System** | Built-in public skills + installable custom skill packages |
| **Tool Extensions** | Built-in tools + community tools + MCP servers |
| **File Processing** | Support for PDF/Word/Excel/PPT upload, parsing, and analysis |
| **RBAC Permissions** | Four-tier role-based access control (Super Admin > Department Admin > User > Viewer) |

### Use Cases

- **Daily Office**: AI-assisted writing, translation, summarization, Q&A
- **Code Development**: Code generation, review, debugging, refactoring
- **Data Analysis**: CSV/Excel data statistics and visualization
- **Document Processing**: PDF/Word document parsing and information extraction
- **Process Automation**: Workflow orchestration, multi-step task automation
- **Knowledge Management**: Enterprise knowledge base Q&A, memory management
