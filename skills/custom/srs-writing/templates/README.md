# 模板模式（可选）占位符约定

本目录用于放置**单位自定义模板**（`.docx`）。模板模式下，srs-writing 技能不再从零搭建文档，
而是「打开模板 → 在占位符标记处插入生成内容 → 保存」。

## 启用条件

目录下存在任意 `.docx` 模板文件即启用模板模式。模板命名建议 `srs_template.docx`。

## 占位符约定

在模板正文中插入**独立一行**的占位符文本，agent 用 officecli 定位并替换为生成内容：

| 占位符 | 插入位置 | 替换内容 |
|--------|---------|---------|
| `{{SRS_BODY}}` | 第 3~5 章正文起始处 | 全部自动生成内容（需求/合格性/追踪矩阵） |
| `{{CH3}}` | 第 3 章开篇 | 需求章节内容 |
| `{{CH4}}` | 第 4 章开篇 | 合格性规定汇总表 |
| `{{CH5}}` | 第 5 章开篇 | 需求可追踪矩阵 |

- 放置**单一 `{{SRS_BODY}}`** 最简单；需要把内容拆到不同章节时用 `{{CH3}}/{{CH4}}/{{CH5}}` 组合。
- 占位符必须是**独立成行**的文本，不得混在段落里。

## 处理流程

1. agent 用 officecli 打开模板，`view` 出大纲找到占位符行；
2. 在占位符处插入生成内容（章节标题保持模板既有格式）；
3. 删除占位符行（用 officecli `remove` 定位到行删除）；
4. 封面、引言、引用文件等**模板已有内容不修改**（单位名称、密级、编号由单位预先填好）。

## 故障兜底

模板中找不到任一占位符 → 回退到普通模式（从零搭建），并在回复中提示「模板未放置占位符，已使用默认结构」。
