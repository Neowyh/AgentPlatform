# Security Policy

## Supported Versions

As ideer doesn't provide an official release yet, please use the latest version for the security updates.
Currently, we have two branches to maintain:
* main branch for ideer 2.x
* main-1.x branch for ideer 1.x 

## Reporting a Vulnerability

Please go to https://github.com/bytedance/ideer/security to report the vulnerability you find.
