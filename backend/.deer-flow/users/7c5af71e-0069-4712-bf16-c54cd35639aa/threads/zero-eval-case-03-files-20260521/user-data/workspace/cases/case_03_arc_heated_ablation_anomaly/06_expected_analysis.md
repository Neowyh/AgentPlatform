# Case 03 人工期望分析

该文件只供人工验收使用，不建议上传给归零智能体。

## 期望识别的主线

智能体不应给出单一确认根因。合理输出应把“喷流整体超限”评为低倾向，把“P-3 装夹局部偏差”和“材料局部缺陷”列为待验证或中等倾向。

## 关键证据

| 证据 | 等级 | 期望用途 |
| --- | --- | --- |
| `04_test_data.csv` 中 P-3 烧蚀深度和质量损失显著高于其他样件 | A | 支持顶事件事实 |
| `03_test_summary试验总结报告.md` 中热流均值和弧电流稳定 | A | 反证喷流整体超限 |
| `03_test_summary试验总结报告.md` 中照片疑似垫片未贴合 | C | 只能作为装夹偏差线索 |
| `03_test_summary试验总结报告.md` 中材料复检未完成 | D | 要求材料局部缺陷保持待验证 |
| `05_historical_or_review_notes.md` 中 P-4 同批未异常 | B | 反证批次系统性问题 |

## 期望输出特征

- `fault_tree.json` 应至少包含喷流超限、装夹偏差、材料局部缺陷、测量误差四类底事件。
- 对装夹偏差不能给高置信确认，因为核心证据只是照片疑似线索。
- 对材料批次系统性问题应降低倾向，但材料局部缺陷仍需复检。
- 验证计划应包含夹具复测、照片测量复核、B26-042 局部密度/孔隙率复检、同批备件复验。
