# 电弧加热试验大纲

## 试验流程

1. 对热流计进行试前标定。
2. 逐件安装样件并记录装夹偏角。
3. 每件样件暴露 75 s。
4. 试后记录质量损失、烧蚀深度和表面形貌。
5. 异常样件进行材料批次复检。

## 数据记录

| 数据项 | 频率或次数 | 用途 |
| --- | --- | --- |
| 热流计读数 | 10 Hz | 判断喷流稳定性 |
| 弧电流 | 10 Hz | 判断能量输入 |
| 样件背温 | 2 Hz | 判断热穿透趋势 |
| 烧蚀深度 | 每件 5 点 | 判断材料响应 |
| 装夹偏角 | 每件 1 次 | 判断入射角影响 |

## 异常处置

若单件样件异常而喷流参数正常，应优先保留样件、复核装夹记录和材料批次，不得直接判定材料失效。
