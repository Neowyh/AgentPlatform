# 01: 核心知识包提取

**What to build:** 嵌入式开发者可调用“芯片软件开发包提取”专业 Skill，提交一个合格的单型号、单封装 Chip software source set 后，获得可下载的 Embedded software knowledge brief 和结构化附表；关键结论可回溯到原厂资料。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 合格资料集的一次 Skill 运行生成 Markdown 简报和结构化附表两份工件。
- [ ] 每份工件明确目标型号、封装和资料覆盖范围，并包含可用的来源定位。
- [ ] 行为测试从用户可调用的 Skill 运行验证工件，不依赖提示词或 PDF 转换内部实现。
