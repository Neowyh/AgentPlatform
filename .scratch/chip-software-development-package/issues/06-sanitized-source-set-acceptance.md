# 06: 脱敏文档集验收

**What to build:** 维护者可用一组脱敏、固定的芯片原厂资料样本验证完整体验：资料边界、两份工件、来源、Evidence status、下游门禁和离线可用性在升级后仍保持正确。

**Blocked by:** 02: 文档集身份与资料缺口校验; 03: 证据状态与人工复核门禁; 04: 嵌入式开发关键知识覆盖; 05: 受控下游消费与离线发布.

**Status:** ready-for-agent

- [ ] 验收样本包含单封装正常资料、缺资料、多封装混入、勘误冲突和复杂跨页表格。
- [ ] 端到端验证两份工件可访问、每个关键结论有来源定位，且不确定内容保留为 `review_required`。
- [ ] 运行相应标准测试和 `pr-standard`；涉及真实离线部署时，验证打包资产可用。
