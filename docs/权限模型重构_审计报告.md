## 二、已完全实现的需求（无偏差）

### 数据库层
- resource_metadata 表：全部字段、约束、索引与设计文档完全一致
- visibility_applications 表：含 pending 唯一索引、status/visibility 枚举校验
- Alembic 迁移脚本、.meta.json 迁移脚本、skill_applications 迁移脚本均已实现
- skill_default_configs 和 user_skill_preferences 表在后端 app 目录中已无引用

### 权限函数统一
- authz.py 的 check_resource_modify 仅检查 owner，admin 无特殊权限
- check_resource_access 无 department_admin 隐式分支
- skills.py 中的 _check_resource_modify、_is_visible_to_user 已删除
- agents.py 中的 _check_resource_modify、_can_set_visibility 已删除
- skills.py 的 update_skill_visibility 端点已移除

### 审批流程 API
- 四个端点全部实现：POST 创建、PUT 撤回、PUT 审批、GET 列表
- 审批使用乐观锁、dept_admin 自审检查、审批后自动同步 resource_metadata.visibility
- 旧 skill-applications 端点已标记 410 Gone

### 错误码体系
- 12 个错误码全部在 error_codes.py 中定义，HTTP 状态码与文档一致

### 管理员人数限制
- 后端 admin.py 角色变更时校验 super_admin ≤2、dept_admin ≤3

### 用户调岗处理
- admin.py update_user 中实现：department 级资源降级 private、pending 申请自动关闭/重分配

### 用户禁用处理
- admin.py disable_user 中实现：资源数量检查（TRANSFER_REQUIRED）、pending 申请自动驳回/重分配

## 三、部分实现的需求（存在偏差）

### 3.1 部门删除 — 资源重分配
**文档要求**: 部门删除前需 super_admin 执行资源重分配（选择继承或指定新 owner）
**实际实现**: 后端直接将 department 级资源降级为 private 并清除 department_id，无重分配 UI 流程
**偏差**: 缺少前端重分配对话框，用户无法选择资源归属，而是自动降级处理

### 3.2 导出功能
**文档要求**: Skill/Workflow/Agent 均支持 ZIP 导出（含内容文件 + meta.json）
**实际实现**: Agent 导出已实现（agent-card 中有 DownloadIcon 按钮），但 Skill 和 Workflow 的导出端点未在当前路由中找到
**偏差**: 仅 Agent 导出完整，Skill/Workflow 导出缺失

### 3.3 导入功能
**文档要求**: Skill/Workflow/Agent 均支持导入，visibility 默认 private
**实际实现**: Agent 导入已实现（agent-gallery 中有文件上传），Skill/Workflow 导入端点未找到
**偏差**: 仅 Agent 导入完整

### 3.4 Workflow/Agent 编辑页 owner 校验
**文档要求**: 编辑页仅 owner 可编辑
**实际实现**: 后端 check_resource_modify 已强制 owner-only，但前端编辑页未显示 owner 限制提示
**偏差**: 后端权限正确，前端缺少非 owner 的只读提示或编辑按钮禁用

### 3.5 设置→技能页面
**文档要求**: 删除功能移除，改为只读列表
**实际实现**: skill-settings-page.tsx 仍包含 skill-apply-dialog.tsx（visibility 申请对话框），不是纯只读
**偏差**: 保留了申请功能（可能是有意为之），但与"删除功能移除"的描述有差异

### 3.6 分页参数
**文档要求**: 所有列表接口支持 page/page_size/sort_by/sort_order
**实际实现**: visibility_applications 支持 page/page_size，但部分端点缺少 sort_by/sort_order 参数
**偏差**: 排序参数未完全覆盖

## 四、未实现的需求

**优先级**: 中 — 属于体验优化

**优先级**: 低 — 后端已拦截，前端提示可后续补充
