# Case 04 问题描述：电机监测超限告警与原始数据不一致

## 顶事件

风机电机监测系统热试验第 3 工况保持阶段，监测软件持续上报"HF-07 通道热流超限"告警，
但导出的原始数据中该通道测值始终低于报警阈值，告警与原始数据不一致。

## 发生条件

- 试验日期：2026-05-12
- 试验阶段：第 3 工况保持（目标转速 1 800 rpm）
- 异常时间：T+00:41:00 起间歇出现，共 17 次
- 影响范围：告警可信度存疑，试验未中断；监测软件版本 V2.3.1

## 当前状态

试验后复测采集通道硬件正常。监测软件由协作厂商提供，源码随代码证据包提供
（含一个 GB18030 编码的历史解析模块与固件描述表二进制），要求结合静态扫描
与日志证据定位告警误报来源，软件侧结论允许待验证。

## 已有资料

1. 问题描述（本文件）。
2. 代码证据包：`motor_monitor.c`（状态判定与标签映射）、`gb_log_parse.c`
   （日志解析，GB18030 编码）、`firmware_table.bin`（固件描述表）。
