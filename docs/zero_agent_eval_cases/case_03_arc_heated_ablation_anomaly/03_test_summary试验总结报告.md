# 电弧加热试验总结报告

## 异常现象

P-3 试后中央区域烧蚀深度为 1.42 mm，P-1、P-2、P-4 分别为 0.84 mm、0.88 mm、0.91 mm。P-3 表面出现偏右侧条带状加深，但试验段热流计均值为 2.43 MW/m2，未超过热流判据。

## 排查记录

| 排查项 | 结果 | 证据等级 |
| --- | --- | --- |
| 热流计标定 | 试前标定偏差 +1.8% | A |
| 喷流热流稳定性 | P-3 暴露期间均值 2.43 MW/m2，峰值 2.51 MW/m2 | A |
| 弧电流稳定性 | P-3 暴露期间最大波动 2.2% | A |
| 装夹偏角记录 | P-3 记录为 0.8 deg，但照片显示边缘垫片疑似未完全贴合 | C |
| 材料批次 | P-3/P-4 同属 B26-042，P-4 未异常 | A |
| 材料复检 | 尚未完成密度和孔隙率复测 | D |

## 初步判断

当前证据不足以确认材料批次问题。喷流整体超限可能性较低，P-3 装夹局部偏差和材料局部缺陷均需进一步验证。

## 未关闭问题

1. P-3 装夹偏角需要依据原始照片和夹具复测确认。
2. B26-042 批次局部密度、孔隙率复检未完成。
3. 需要补做 P-3 相同批次备件复验。
