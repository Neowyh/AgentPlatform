# 归零智能体评测伪数据案例集

本目录用于验证归零排故智能体在风洞试验、热真空试验和电弧加热热试验中的资料读取、证据抽取、故障树构建、底事件评估、根因归因和归零报告生成能力。

全部资料均为脱敏伪数据，不对应真实型号、真实试验编号、真实设备编号或真实人员。

## 使用方式

每次只上传一个案例目录中的资料，建议不要上传 `06_expected_analysis.md`，该文件仅供人工评测对照。

推荐提示词：

```text
请基于我上传的资料完成归零排故分析。先读取问题描述、设计方案、试验大纲、试验总结报告和试验数据，构建故障树，评估底事件，生成 fault_tree.json、fault_tree.svg、bottom_event_assessment.md、analysis_process.svg 和 zeroing_report.md，并展示所有输出文件。关键结论必须引用证据来源，证据不足项请标记为待验证。
```

## 案例清单

| 案例 | 场景 | 主要验证点 |
| --- | --- | --- |
| `case_01_wind_tunnel_heat_flux_drift` | 高焓风洞热流测量漂移 | 区分真实热环境异常与测量链路异常 |
| `case_02_thermal_vacuum_temp_overshoot` | 热真空控温超调 | 识别控制参数、热惯性和测点布置的耦合影响 |
| `case_03_arc_heated_ablation_anomaly` | 电弧加热烧蚀异常 | 在证据不足和冲突证据下保持待验证结论 |

## 人工验收维度

| 维度 | 通过要求 |
| --- | --- |
| 资料读取 | 能识别顶事件、发生条件、影响范围、资料清单 |
| 证据引用 | 关键结论包含文件路径，能区分 A/B/C 级证据 |
| 故障树 | 顶事件来自资料原文，底事件可验证，不写笼统原因 |
| 底事件评估 | 同时考虑证据强度、机理一致性、反证和复现实验情况 |
| 根因归因 | 有 A/B 级证据才给较高置信结论，证据不足时标记待验证 |
| 报告闭环 | 输出 `fault_tree.json`、`fault_tree.svg`、`bottom_event_assessment.md`、`analysis_process.svg`、`zeroing_report.md`，报告章节完整且图形产物可查看 |
