# Case 02 人工期望分析

该文件只供人工验收使用，不建议上传给归零智能体。

## 期望识别的主线

智能体应识别“参数组 B 切换后加热占空比下降过慢”是高倾向底事件，TC-12 胶层偏厚是中低倾向干扰项或待验证项。

## 关键证据

| 证据 | 等级 | 期望用途 |
| --- | --- | --- |
| `04_test_data.csv` 中保温后 HZ-2 占空比 120 s 内仍高于 58% | A | 支持控制参数异常 |
| `03_test_summary试验总结报告.md` 中参数组 B 版本前一日变更 | B | 支持配置变更线索 |
| `04_test_data.csv` 中外壁温度未明显超限而内部继续升温 | A | 支持热惯性和控制耦合 |
| `05_historical_or_review_notes.md` 中相似积分限幅案例 | B | 支持验证路径，但不能直接作为本次根因 |

## 期望输出特征

- 故障树应包含控制参数配置、热惯性模型偏差、TC-12 安装状态、真空环境异常等底事件。
- 真空环境异常应低倾向，因为真空度稳定。
- 不应把 TC-12 胶层偏厚直接判为根因。
- 验证计划应包含参数组 B 配置复核、控制程序回放、参数组 C 短时复现实验、TC-12 胶层厚度复测。
