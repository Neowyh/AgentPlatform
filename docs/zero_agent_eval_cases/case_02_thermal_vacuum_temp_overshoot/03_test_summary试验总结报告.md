# 热真空试验总结报告

## 异常现象

升温结束后控制程序从参数组 A 切换至参数组 B。TC-09、TC-10 外壁测点维持在 84.6 C 至 86.2 C，TC-12 内部测点继续上升至 94.6 C，超过内部超调判据。

## 排查记录

| 排查项 | 结果 | 证据等级 |
| --- | --- | --- |
| 真空度 | 异常期间 3.0e-3 Pa 至 3.5e-3 Pa | A |
| 外壁反馈 | TC-09/TC-10 未超出判据 | A |
| 加热占空比 | 切保温后 120 s 内仍保持 58% 以上 | A |
| 热电偶目视复查 | TC-12 未脱落，胶层偏厚需复测 | B |
| 参数组 B 版本 | 试验前一日从 2026B-2 改为 2026B-3 | B |

## 初步判断

内部超调与保温参数切换后的占空比下降过慢高度相关，TC-12 胶层偏厚可能影响动态响应，但不能单独解释持续超调。

## 未关闭问题

1. 参数组 B 的积分限幅值是否误配置，待软件配置复核。
2. TC-12 导热胶厚度未复测。
3. 需要用参数组 C 进行一次短时复现实验。
