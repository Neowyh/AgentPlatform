# 热真空试验大纲

## 试验步骤

1. 完成热电偶导通和极性检查。
2. 抽真空至优于 5e-3 Pa。
3. 以 1.2 C/min 升温至 85 C。
4. 自动切换至保温参数组 B。
5. 保温 90 min，采样频率 1 Hz。

## 判据

| 项目 | 判据 |
| --- | --- |
| 真空度 | 保持优于 5e-3 Pa |
| 外壁温度 | 85 +/- 3 C |
| 内部测点超调 | 不超过 89 C，持续不超过 180 s |
| 加热占空比 | 切保温后 60 s 内低于 35% |

## 异常处置

内部温度超过 89 C 且持续超过 180 s 时，人工切换至保守保温参数组 C，并记录切换前后控制量。
