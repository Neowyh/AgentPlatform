# 基于 deer-flow 框架开发归零排故智能体的分析方案

## 1. 主要结论

基于 deer-flow 开发归零排故智能体可行。deer-flow 已具备智能体运行、前端工作台、模型接入、Skill、MCP、工具调用、Artifacts 和记忆能力，可以作为底座使用。

需要新增的是归零排故业务层：问题单、流程状态、报告模板、证据链、评审闭环、权限审计和企业系统接入。建议按“先智能体验证，再补业务工作台，再做生产级集成”的顺序推进。

## 2. 功能需求拆解

| 需求点    | 细化内容                                 |
| ------ | ------------------------------------ |
| 工作台入口  | 支持问题创建、材料上传、对话分析、过程跟踪、报告导出、评审查看      |
| 问题单结构化 | 记录问题现象、影响范围、复现条件、责任模块、验证状态、关闭结论      |
| 智能体流程  | 按澄清问题、收集证据、提出根因假设、设计验证方案、生成报告的顺序执行   |
| 子任务编排  | 支持日志分析、资料检索、代码排查、测试方案生成等子任务          |
| 知识接入   | 接入历史问题、设计文档、测试记录、代码变更、日志、标准规范和专家经验   |
| 工具能力   | 支持资料读取、知识检索、日志分析、图表生成、脚本执行、报告输出      |
| 流程状态   | 覆盖问题受理、信息补全、初步分析、根因验证、措施制定、验证关闭、复盘归档 |
| 报告与证据  | 保留证据引用、报告版本、评审意见和过程记录                |
| 权限审计   | 支持多用户、多项目隔离、角色权限、敏感信息脱敏、工具调用审计       |
| 高风险控制  | 命令执行、外部系统写入、Skill 自演化默认关闭，按审批启用      |

## 3. deer-flow 能力对应与补齐点

| 所需能力   | deer-flow 当前能力                                      | 补齐点                               |
| ------ | --------------------------------------------------- | --------------------------------- |
| 前端工作台  | 已有 Next.js 工作台、聊天、历史会话、文件上传、Artifacts、设置中心          | 仅补通用智能体配置入口、模板选择和运行记录查看，暂不做归零专用页面 |
| 自定义智能体 | 已有 Agent CRUD、`config.yaml`、`SOUL.md`、前端创建 Agent 流程 | 增加通用 Agent 模板、场景配置和工具权限配置         |
| 流程固化   | 已有 Skill 机制，可启停、安装、编辑自定义 Skill                      | 建立可配置流程模板与 Skill 模块，归零流程作为样例模板    |
| 模型接入   | 支持 OpenAI-compatible、Ollama、vLLM、MindIE 等           | 验证本地模型的 tool calling、长上下文和稳定性     |
| 工具接入   | 已有 Web、文件、沙箱、MCP、ACP、子智能体工具机制                       | 接入企业通用数据源和只读工具，按场景配置可用工具          |
| 文件与产物  | 已支持上传、读取、生成、预览、下载 Artifacts                         | 增加通用产物模板、引用关系和导出能力                |
| 记忆与历史  | 已有 thread、memory、run events、token usage             | 建立智能体/场景级记忆和历史任务复用能力              |
| 流程状态   | 当前以对话 thread 为主                                     | 新增可配置流程状态和任务实例管理                  |
| 权限审计   | 有基础认证和用户级 Agent 隔离                                  | 增加项目/角色权限、工具审计和敏感操作审批             |
| 评测体系   | 有工程测试框架                                             | 建立多场景智能体评测集和质量评估指标                |
