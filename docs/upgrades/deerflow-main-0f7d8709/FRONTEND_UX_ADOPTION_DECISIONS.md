# 合并 DeerFlow 后的前端体验决策

状态：产品决策已确定，尚待按本清单实施和验收。以合并前 iDeer 前端 `dbb2a813` 为原有体验基准；本轮 DeerFlow 上游版本为 `0f7d8709`。

## 总原则

原有页面保留原菜单位置、布局、文案和常用操作路径。新增功能逐项接入，在对应位置给出清楚入口。仅有旧网址继续可访问，不等于页面体验已恢复。

## 按 WebUI 位置核对

| 在哪里找 | 确定的界面和操作 | 何时出现或生效 |
| --- | --- | --- |
| 新对话页 | 保留 iDeer 欢迎标题，移除其下“欢迎使用 iDeer，一个完全开源的超级智能体……”长介绍和页面内“最近的对话”卡片；左侧对话历史和完整对话列表继续保留。调整剩余模块高度与间距，使常用桌面视口中欢迎标题、场景入口、输入区可同时完整显示；窄屏或矮屏可自然滚动，但不裁切、叠压或遮住按钮。 | 新建对话且尚未发送消息时；无论是否已有历史对话，页面内卡片都不出现。 |
| 新对话页的输入区和底部 | 附件、语音、模型、技能等控件的文字字号与正文一致；纯图标按钮保持清楚且易点击。删除输入框下方“小惊喜、写作、研究”等重复静态快捷按钮及仅供它们使用的代码，保留上方场景和专家快捷入口。保留“工作复盘？iDeer带你回到过去”的最近任务卡片并上移，核查提示“内容由AI生成，重要信息请务必核查”放在页面内容底部。输入 `/` 与右下角技能按钮选中同一技能后，显示、光标位置和发送效果一致；选中、切换、移除技能不会让新对话页输入框的外框变宽或变高。切换模型、技能、语音、场景等状态时，其他模块不应无故变形或跳位。 | 打开新对话页时；有历史任务才显示最近任务卡片，没有历史时该区域消失属于预期变化。弹层出现、普通多行输入增长也可按原规则改变画面。 |
| 左侧菜单 | 保留原有“聊天 → 专家·技能·连接器 → 工作流 → 资料库”的顺序。“专家”使用原能力中心页面；取消重复的独立专家管理入口。“定时任务”是独立新入口，排在这些旧菜单之后。 | 登录后进入工作台。 |
| 原“专家·技能·连接器” | DeerFlow 增加的专家创建、设置能力合进原专家页。技能归原技能页管理；当前“设置 → 工具”里配置的是 MCP 服务，应归原连接器页，沿用原权限要求。系统级工具仍由管理员页面管理。 | 打开能力中心时。 |
| “设置”弹窗 | 原有“账号、外观、通知、记忆、关于”位置不动。设置中的旧“技能”“工具”链接分别跳转到能力中心的技能页、连接器页，不保留第二套管理页。 | 打开设置或旧链接时。 |
| “设置 → 渠道 / 集成” | 仅展示部署中实际可用的项目。默认隐藏需要公网的云服务入口；配置了可用内网渠道才显示该渠道，能够访问飞书的部署才显示飞书集成。 | 对应服务已配置且在部署环境中可用时。 |
| 聊天输入框 | 原附件、模型、技能控件留在原位置。语音输入和“优化输入”按钮直接放在输入框下方。草稿自动保留当前会话的文字和已选技能；发出后清除。 | 语音需浏览器支持；优化输入由用户点击，改写后的文字仍由用户确认发送。当前草稿实现只覆盖会话中的文字和技能，不能承诺附件或关闭标签后的恢复。 |
| 自己最近一条提问 | 在该消息的“更多操作”中提供“编辑并重新运行”。 | 用户点击后修改原问题并重新发起；旧回答随之更新，但此前对外部文件或服务造成的效果不会自动撤销。 |
| AI 回复 | 在该回复的“更多操作”中提供“分叉对话”。选中回复文字后可点“在侧边聊天中提问”。 | 分叉从选定回复开始新会话；侧边聊天只在用户选中文字并点击后打开。 |
| 左侧最近对话 | 在对应会话的“更多操作”中提供“置顶”。 | 用户主动点击后，这条会话固定在近期列表前面。 |
| 长对话 | 显示章节大纲入口，点击可跳到相应位置。 | 达到现有长对话条件时出现；普通短对话不占位置。 |
| 聊天右侧的浏览器面板 | 这是供 AI 操作网页的独立浏览器画面，并非用户访问本平台的浏览器。新画面只给提示；用户点击后才打开面板。 | 部署已开启浏览器能力、当前对话可用，且 AI 使用该能力时才有入口或画面。普通聊天不自动变窄。 |
| 聊天中的文件变更提示 | AI 确实修改工作文件后才显示入口；用户点击查看改动。 | 没有改动时维持原聊天布局。 |
| 原文件预览区 | 保持原打开和预览方式，在同一区域增加“直接编辑”和“打包下载”。 | 打开生成文件时。 |
| 登录页 | 保留原邮箱、密码、登录按钮。追加“记住登录”勾选框，初始不勾选；用户勾选才请求保持登录。企业身份系统已配置且可访问时，才追加“企业账号登录”按钮。 | 不勾选记住登录时应使用浏览器会话级登录；这与当前后端在安全连接或本机可能默认保持登录的行为不同，实施时必须显式传递用户选择。未配置企业身份系统的部署仍只有原登录入口。 |

## 验收时看什么

1. 对照合并前页面或已有截图，逐页确认原菜单顺序、布局、文案和常用点击路径；覆盖聊天、专家·技能·连接器、工作流、资料库、设置、登录及原文件预览。
2. 在未配置新增能力的离线部署中，确认云渠道、飞书集成、企业登录和 AI 浏览器入口不会误导用户；旧页面仍可按原路径使用。
3. 在配置了对应能力的部署中，逐项从上表指定位置进入并完成操作；右侧面板只在用户点击后打开。
4. 确认“记住登录”默认不勾选时的实际登录持续行为，不以勾选框外观代替验证。
