# 归零排故智能体 PoC 验证记录

## 安装准备

1. 将 `docs/fault-zeroing-agent/agent/config.yaml` 和 `docs/fault-zeroing-agent/agent/SOUL.md` 安装到当前用户的 iDeer custom agent 目录。
2. 运行 `python scripts/seed_fault_zeroing_workflow.py` 将 `workflows/fault-zeroing.yaml` 入库（幂等，重复执行会跳过已入库版本）。`docs/fault-zeroing-agent/subagents.yaml` 已废弃（`deprecated`），安装脚本不再引用。
3. 确认 `resources/skills/fault-zeroing/SKILL.md` 存在。
4. 启动 iDeer 后选择 `fault-zeroing` 智能体并触发对应工作流。
