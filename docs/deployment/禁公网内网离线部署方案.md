# DeerFlow 禁公网内网离线部署方案

## Summary

本方案面向禁公网、`x86_64/amd64`、离线 `tar` 包交付、本地沙箱模式。目标是把当前 DeerFlow 源码版本打包成一套可重复生成的离线部署包，便于在企业内网完成导入、启动和后续版本升级。

默认交付物放在 `dist/intranet/deer-flow-<version>/`，包含：

- `deer-flow-images-<version>.tar`
- `deer-flow-source-<version>.tar.gz`
- `docker-compose.intranet.yaml`
- `禁公网内网离线部署作业指导书.md`
- `MANIFEST.txt`
- `SHA256SUMS`
- `env.intranet.example`

## Key Changes

- 新增一键打包脚本 `scripts/package-intranet-offline.sh`
  - 默认只打包 `gateway`、`frontend`、`nginx`
  - 默认平台为 `linux/amd64`
  - 支持 `--version`、`--output-dir`、`--force`、`--no-cache`、`--require-clean`
  - 重复执行时使用稳定版本号和固定输出目录，减少人工改名和误覆盖
  - 自动生成离线 compose 文件、环境变量模板、清单和校验和

- 新增离线部署用 compose 文件
  - 仅使用 `image:`，不保留 `build:`
  - 运行配置继续从宿主机挂载，不写入镜像
  - `config.yaml` 可在内网部署后单独修改并重启 `gateway`

- 新增作业指导书
  - 说明构建机打包、文件传输、内网导入、启动、回滚和常见故障处理
  - 把每一步命令写成可直接复制执行的形式

## Test Plan

- 执行脚本语法检查
  - `bash -n scripts/package-intranet-offline.sh`
- 执行一次离线包生成
  - `scripts/package-intranet-offline.sh --version test-local`
- 校验输出
  - 确认输出目录包含镜像包、源码包、compose、清单和校验和
  - 确认 `SHA256SUMS` 可通过校验
- 内网导入验证
  - `docker load -i deer-flow-images-test-local.tar`
  - 使用离线 compose 启动 `nginx`、`frontend`、`gateway`
  - 修改 `config.yaml` 中的模型服务地址后重启 `gateway`，确认配置可独立变更

## Assumptions

- 首版只覆盖本地沙箱模式，不包含 Docker sandbox 和 Kubernetes provisioner
- 首版只做离线 `tar` 交付，不依赖内网镜像仓库
- 运行配置通过宿主机文件管理，不写入镜像
- 内网服务器默认采用 `docker compose` v2
