# Skill RBAC 权限机制改进开发计划

## 一、需求概述

### 当前问题
1. Skill 启用/禁用是全局配置，所有用户共享同一个配置
2. 用户无法控制自己使用的 skill
3. 缺少 skill 开放申请和审批机制
4. 缺少 skill 可见性撤回功能

### 目标设计
1. **用户个人偏好**：每个用户可以控制自己使用的 skill
2. **开放申请机制**：用户创建的 skill 可以申请向部门或全员开放
3. **审批流程**：部门开放需部门管理员审批，全员开放需超级管理员审批
4. **管理员控制**：管理员可以设置默认启用的 skill，并控制是否允许用户覆盖

```python
def load_skills_for_user(self, user_id: str, department_id: str | None = None) -> list[Skill]:
    """加载用户可用的 skill，合并默认配置和用户偏好"""
    # 1. 获取用户有权限访问的 skill
    accessible_skills = self._get_accessible_skills(user_id, department_id)
    
    # 2. 获取全局默认配置
    global_defaults = get_global_skill_defaults()
    
    # 3. 获取部门默认配置
    dept_defaults = get_dept_skill_defaults(department_id) if department_id else {}
    
    # 4. 获取用户个人偏好
    user_prefs = get_user_skill_preferences(user_id)
    
    # 5. 合并配置（优先级：用户偏好 > 部门默认 > 全局默认）
    effective_skills = []
    for skill in accessible_skills:
        enabled = resolve_skill_enabled(
            skill,
            user_prefs=user_prefs,
            dept_defaults=dept_defaults,
            global_defaults=global_defaults
        )
        if enabled:
            effective_skills.append(skill)
    
    return effective_skills
```

### 3. Skill 可见性检查逻辑

**修改文件**: `backend/packages/harness/ideer/skills/storage/skill_storage.py`

```python
def _get_accessible_skills(self, user_id: str, department_id: str | None) -> list[Skill]:
    """获取用户有权限访问的 skill"""
    all_skills = self.load_skills(enabled_only=False)
    
    accessible = []
    for skill in all_skills:
        if self._is_skill_accessible(skill, user_id, department_id):
            accessible.append(skill)
    
    return accessible

def _is_skill_accessible(self, skill: Skill, user_id: str, department_id: str | None) -> bool:
    """检查用户是否有权限访问 skill"""
    # public skill 对所有人可见
    if skill.visibility == ResourceVisibility.PUBLIC:
        return True
    
    # department skill 对同部门用户可见
    if skill.visibility == ResourceVisibility.DEPARTMENT:
        return department_id and skill.department_id == department_id
    
    # private skill 仅对所有者可见
    return skill.owner_id == user_id
```

## 八、验证方案

### 功能验证
1. 用户登录后可以在 workspace 技能管理页面看到所有可用 skill
2. 用户可以切换 `custom` 类型 skill 的启用/禁用状态
3. 用户无法修改 `public` 类型 skill 的启用状态（显示为锁定）
4. 用户创建的 skill 可以申请向部门或全员开放
5. 管理员可以在 admin 审批页面看到待审批申请
6. 管理员可以批准或拒绝申请
7. 申请通过后，skill 的可见性正确变化
8. 管理员可以在 admin 默认配置页面设置全局默认启用的 skill
9. 管理员可以为不同部门设置差异化的默认配置
10. 管理员可以控制是否允许用户覆盖默认配置

### 权限验证
1. 普通用户无法访问 admin 页面
2. 部门管理员只能审批部门内的申请
3. 超级管理员可以审批所有申请
4. 用户只能操作自己创建的 skill
5. 用户只能切换自己有权限的 skill 的启用状态

### 边界情况验证
1. 并发申请的处理
2. 申请被拒绝后的重新申请
3. 撤回已开放的可见性
4. 管理员修改默认配置后的影响范围
5. 部门配置与全局配置的优先级
