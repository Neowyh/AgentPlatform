# department_admin 权限下放：管理本部门成员

## 目标

让 `department_admin` 角色能管理**自己部门内的普通用户**（查看列表、修改角色、禁用），同时保持 super_admin 的完整权限不变。

## 权限矩阵

| 操作 | super_admin | department_admin | user / viewer |
|------|-------------|-----------------|---------------|
| 查看统计 | ✅ 全局 | ❌ | ❌ |
| 查看用户列表 | ✅ 所有人 | ✅ 仅本部门 | ❌ |
| 修改用户角色 | ✅ 任何人 | ✅ 仅本部门，不能设为 super_admin | ❌ |
| 禁用用户 | ✅ 任何人 | ✅ 仅本部门的 user/viewer | ❌ |
| 查看部门列表 | ✅ | ✅ | ✅ |
| 创建/修改/删除部门 | ✅ | ❌ | ❌ |

## 边界规则（必须校验）

1. department_admin **不能改自己**（防止提权/降权后失去管理能力）
2. department_admin **不能操作 super_admin**（super_admin 不受部门管辖）
3. department_admin **不能操作其他 department_admin**（防止跨部门或同部门降权）
4. department_admin **不能将角色设为 super_admin**（防止提权）
5. department_admin **操作的目标用户必须与自己同部门**
6. 目标用户 `department_id` 为 null → department_admin 无法操作

## 改动文件

### 1. `backend/app/gateway/routers/admin.py`

#### 1.1 `GET /api/admin/users` — 查看用户列表

**改动**：`@require_role` 从只允许 `SUPER_ADMIN` 改为允许 `SUPER_ADMIN` + `DEPARTMENT_ADMIN`。在函数体中根据角色动态过滤：

```python
@router.get("/users")
@require_role(UserRole.SUPER_ADMIN, UserRole.DEPARTMENT_ADMIN)
async def list_users(
    department_id: str | None = None,
    role: str | None = None,
    ...
    current_user: UserModel = Depends(get_current_rbac_user),
):
    # ... 现有的 valid role 检查 ...
    
    # 新增：department_admin 强制只看本部门，忽略 department_id 参数
    if current_user.role == UserRole.DEPARTMENT_ADMIN:
        if not current_user.department_id:
            return {"users": [], "total": 0, "limit": limit, "offset": offset}
        # 强制覆盖 department_id，忽略传入参数
        department_id = current_user.department_id
    
    # ... 现有的 count + query 逻辑（department_id 已被正确设置）...
```

**说明**：department_admin 传入 `department_id` 参数时会被强制覆盖为自己的部门，传入 `role=super_admin` 时查询自然返回空（super_admin 无 department_id）。无需额外校验。

**`GET /departments` 的 `member_count`**：当前代码第 258 行已对 department_admin 显示 member_count（`role in (SUPER_ADMIN, DEPARTMENT_ADMIN)`），无需改动。

#### 1.2 `PUT /api/admin/users/{user_id}/role` — 修改用户角色

**改动**：`@require_role` 改为允许两个角色。在函数体中增加 department_admin 的校验逻辑：

```python
@router.put("/users/{user_id}/role")
@require_role(UserRole.SUPER_ADMIN, UserRole.DEPARTMENT_ADMIN)
async def update_user_role(...):
    # ... 现有的 valid role 检查和 user 查询 ...
    
    # 新增：department_admin 权限校验
    if current_user.role == UserRole.DEPARTMENT_ADMIN:
        # 不能改自己
        if user_id == current_user.id:
            raise HTTPException(400, "Cannot change your own role")
        # 不能操作 super_admin
        if user.role == UserRole.SUPER_ADMIN:
            raise HTTPException(403, "Cannot modify super_admin")
        # 不能操作其他 department_admin
        if user.role == UserRole.DEPARTMENT_ADMIN:
            raise HTTPException(403, "Cannot modify another department_admin")
        # 不能设为 super_admin
        if body.role == UserRole.SUPER_ADMIN:
            raise HTTPException(403, "Cannot promote to super_admin")
        # 必须同部门
        if user.department_id != current_user.department_id:
            raise HTTPException(403, "Cannot modify users outside your department")
        # 目标必须有部门
        if not user.department_id:
            raise HTTPException(403, "Cannot modify users without a department")
    
    # ... 现有的 last super_admin 检查 ...
```

#### 1.3 `DELETE /api/admin/users/{user_id}` — 禁用用户

**改动**：同上模式：

```python
@router.delete("/users/{user_id}")
@require_role(UserRole.SUPER_ADMIN, UserRole.DEPARTMENT_ADMIN)
async def disable_user(...):
    # ... 现有的 self-disable 检查和 user 查询 ...
    
    # 新增：department_admin 权限校验
    if current_user.role == UserRole.DEPARTMENT_ADMIN:
        # 不能操作 super_admin
        if user.role == UserRole.SUPER_ADMIN:
            raise HTTPException(403, "Cannot disable super_admin")
        # 不能操作其他 department_admin
        if user.role == UserRole.DEPARTMENT_ADMIN:
            raise HTTPException(403, "Cannot disable another department_admin")
        # 必须同部门
        if user.department_id != current_user.department_id:
            raise HTTPException(403, "Cannot disable users outside your department")
        if not user.department_id:
            raise HTTPException(403, "Cannot disable users without a department")
    
    # ... 现有的 last super_admin 检查 ...
```
