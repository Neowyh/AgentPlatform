# 修复 Skill 编辑器弹窗尺寸比例问题

## 问题分析

当前 `DialogContent` 的默认样式包含 `sm:max-w-lg`（512px），虽然传入了 `max-w-4xl`（896px），但 Tailwind-merge 无法覆盖 `sm:` 前缀的变体，导致宽度被限制在 512px，而高度为 90vh，造成"窄高"的失衡比例。

## 修改方案

### 文件: `frontend/src/components/workspace/settings/skill-settings-page.tsx:250`

将:
```tsx
<DialogContent className="h-[90vh] max-w-4xl p-0 flex flex-col" showCloseButton={false}>
```

改为:
```tsx
<DialogContent className="h-[75vh] max-w-[calc(100%-2rem)] sm:max-w-4xl p-0 flex flex-col" showCloseButton={false}>
```

**变更说明:**
1. `max-w-[calc(100%-2rem)] sm:max-w-4xl` — 显式覆盖默认的 `sm:max-w-lg`，确保 sm+ 屏幕宽度为 896px
2. `h-[75vh]` — 从 90vh 降到 75vh，避免弹窗过高
3. `flex flex-col p-0 showCloseButton={false}` — 保持之前修复的布局和关闭按钮
