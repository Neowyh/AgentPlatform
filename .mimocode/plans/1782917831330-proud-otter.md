## 修复 1: `update_skill_visibility` 覆盖 owner_id（HIGH）

**文件**: `backend/app/gateway/routers/skills.py:626-629`

**问题**: 超管/部门管理员修改他人技能可见性时，`meta["owner_id"]` 被无条件覆盖为当前用户。

**修复**: 删除第 627-629 行的 owner_id/department_id 赋值，仅保留 `meta["visibility"]` 更新。

```python
# 修改前 (line 626-629)
meta["visibility"] = new_visibility
meta["owner_id"] = current_user.id
if hasattr(current_user, "department_id"):
    meta["department_id"] = current_user.department_id

# 修改后
meta["visibility"] = new_visibility
```

## 修复 2: 异步缓存踩踏（HIGH）

**文件**: `backend/packages/harness/ideer/skills/storage/skill_storage.py:345-473`

**问题**: 三个缓存函数 `_get_global_skill_defaults`、`_get_dept_skill_defaults`、`_get_user_skill_preferences` 使用 `threading.Lock()` 且仅在写入阶段加锁，多个协程可同时穿透到数据库。

**修复**: 将 `threading.Lock()` 替换为 `asyncio.Lock()`，并将锁覆盖范围扩展到 check-load-store 全流程。

三个函数模式相同，以 `_get_global_skill_defaults` 为例：

```python
# 修改前 (line 345-387)
async def _get_global_skill_defaults(self) -> dict[str, dict]:
    if not hasattr(self, '_global_defaults_cache'):
        self._global_defaults_cache = None
        self._global_defaults_cache_lock = __import__('threading').Lock()
        self._global_defaults_cache_time = 0
    current_time = time.time()
    if self._global_defaults_cache is not None and (current_time - self._global_defaults_cache_time) < 300:
        return self._global_defaults_cache
    # ... DB query ...
    with self._global_defaults_cache_lock:
        self._global_defaults_cache = defaults
        self._global_defaults_cache_time = current_time

# 修改后
import asyncio

async def _get_global_skill_defaults(self) -> dict[str, dict]:
    if not hasattr(self, '_global_defaults_cache'):
        self._global_defaults_cache = None
        self._global_defaults_cache_lock = asyncio.Lock()
        self._global_defaults_cache_time = 0
    async with self._global_defaults_cache_lock:
        current_time = time.time()
        if self._global_defaults_cache is not None and (current_time - self._global_defaults_cache_time) < 300:
            return self._global_defaults_cache
        # ... DB query (移到锁内) ...
        self._global_defaults_cache = defaults
        self._global_defaults_cache_time = current_time
        return defaults
```

对 `_get_dept_skill_defaults` 和 `_get_user_skill_preferences` 做相同改动。

同时修改 `clear_cache` (line 509-526)：将 `clear_cache` 改为 `async def clear_cache`，内部锁改用 `asyncio.Lock()`。需要检查所有调用点并添加 `await`。

**修复**: 给 `_is_skill_accessible` 增加 `role` 参数，添加 `DEPARTMENT_ADMIN` 分支：

```python
# 修改前 (line 319)

# 修改后
def _is_skill_accessible(self, skill: Skill, user_id: str, department_id: str | None, role: str | None = None) -> bool:
    # ... 现有逻辑 ...
    # 在 return False 前添加:
    if role == "department_admin" and department_id and skill_department_id and department_id == skill_department_id:
        return True
```

需要检查 `_is_skill_accessible` 的所有调用点，确保传入 `role` 参数。同时添加缺失的 `super_admin` 检查（与 `_is_visible_to_user` 对齐）。

## 修复 4: 异步上下文中的阻塞 I/O（MEDIUM）

**文件**: `backend/app/gateway/routers/skills.py:608-634`

**问题**: `update_skill_visibility` 在 async 端点中执行同步文件读写。

**修复**: 使用 `asyncio.to_thread` 包装同步文件 I/O 操作：

```python
# 修改前 (line 608-612)
if meta_file.exists():
    try:
        meta = json.loads(meta_file.read_text(encoding="utf-8"))
    except json.JSONDecodeError:
        meta = {}

# 修改后
if meta_file.exists():
    try:
        content = await asyncio.to_thread(meta_file.read_text, encoding="utf-8")
        meta = json.loads(content)
    except json.JSONDecodeError:
        meta = {}

# 修改前 (line 632-634)
skill_dir.mkdir(parents=True, exist_ok=True)
with open(meta_file, "w", encoding="utf-8") as f:
    json.dump(meta, f, indent=2)

# 修改后
await asyncio.to_thread(skill_dir.mkdir, parents=True, exist_ok=True)

def _write_meta(path, data):
    with open(path, "w", encoding="utf-8") as f:
        json.dump(data, f, indent=2)

await asyncio.to_thread(_write_meta, meta_file, meta)
```
