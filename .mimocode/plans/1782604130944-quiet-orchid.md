# 修复技能管理页面两个 Bug

## 问题概述

### Bug 1：启停按钮无效
- **现象**：点击 Switch 按钮后立即回弹，无任何反馈
- **根因**：`useEnableSkill` hook 没有 `onError` 处理，API 错误被 tanstack-query 的 `mutate` 静默吞掉；受控 Switch 的 `checked` prop 未更新导致回弹

### Bug 2：编辑页面渲染显示错误
- **现象**：打开编辑弹窗后内容显示异常
- **根因**：`initialContent` 是硬编码模板字符串（`skill-settings-page.tsx:196-204`），不是从 API 获取的真实 SKILL.md 内容；`handleSaveSkill` 是空实现（TODO）；预览渲染的 HTML 不合法（`<li>` 无父 `<ul>`/`<ol>`）

---

## 修复方案

### 改动 1：为 `useEnableSkill` 添加错误处理

**文件**: `frontend/src/core/skills/hooks.ts`

- 在 `useMutation` 中添加 `onError` 回调，调用 `toast.error()` 显示错误信息
- 引入 `toast` from `sonner`（项目已有的 toast 库）

```typescript
import { toast } from "sonner";

export function useEnableSkill() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: async ({ skillName, enabled }: { skillName: string; enabled: boolean }) => {
      await enableSkill(skillName, enabled);
    },
    onSuccess: () => {
      void queryClient.invalidateQueries({ queryKey: ["skills"] });
    },
    onError: (error) => {
      toast.error(error instanceof Error ? error.message : "Failed to update skill");
    },
  });
}
```

### 改动 2：新增前端 API 函数获取技能内容

**文件**: `frontend/src/core/skills/api.ts`

新增两个函数：

1. `getCustomSkillContent(skillName: string)` — 调用 `GET /api/skills/custom/{skillName}` 获取真实 SKILL.md 内容
2. `updateCustomSkillContent(skillName: string, content: string)` — 调用 `PUT /api/skills/custom/{skillName}` 保存编辑后的内容

后端已有对应端点（`skills.py:266-297` 和 `skills.py:300-346`），前端直接对接。

### 改动 3：新增 hook 获取/更新技能内容

**文件**: `frontend/src/core/skills/hooks.ts`

新增两个 hook：

1. `useCustomSkillContent(skillName: string | null)` — 使用 `useQuery` 获取技能内容，仅在 `skillName` 非空时启用
2. `useUpdateCustomSkill()` — 使用 `useMutation` 更新技能内容，成功时刷新内容缓存并显示 toast

### 改动 4：修复技能编辑器弹窗

**文件**: `frontend/src/components/workspace/settings/skill-settings-page.tsx`

- 打开编辑弹窗时，通过 `useCustomSkillContent` 获取真实 SKILL.md 内容
- 将 `initialContent` 从硬编码模板改为从 API 返回的实际内容
- 替换空的 `handleSaveSkill` 为调用 `useUpdateCustomSkill` 的实现
- 仅对 `category === "custom"` 的技能显示编辑按钮（公共技能不可编辑）
- 添加加载状态：内容获取中时显示 loading 指示器

### 改动 5：修复预览渲染的 HTML 合法性

**文件**: `frontend/src/components/workspace/settings/skill-editor.tsx`

修复 `renderPreview` 函数中的 HTML 问题：

1. `<li>` 元素包裹在 `<ul>` 或 `<ol>` 中
2. 修复段落标签嵌套问题（避免 `</p>` 在开头）
3. 将 `<br />` 替换为段落分隔
