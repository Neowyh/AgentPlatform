# GB/T 9704-2012 公文格式标准速查

## 公文用纸

- 规格：A4 (210mm × 297mm)
- 制版：双面印刷

## 版面尺寸

| 要素 | 规格 |
|------|------|
| 上白边 | 37mm ± 1mm |
| 下白边 | 35mm ± 1mm |
| 左白边 | 28mm ± 1mm |
| 右白边 | 26mm ± 1mm |
| 每行字数 | 28个字 |
| 每页行数 | 22行 |
| 行距 | 固定值 28.95pt |

## 公文三大组成区域

### 一、版头（红头）

从上至下依次为：

1. **份号**（涉密公文必须标注）
   - 位置：版心左上角第1行
   - 字体：3号阿拉伯数字

2. **密级和保密期限**
   - 位置：份号下方
   - 字体：3号黑体
   - 格式："秘密★1年""机密★3年""绝密★长期"

3. **紧急程度**
   - 位置：密级下方
   - 字体：3号黑体
   - 电报："特提""特急""加急""平急"
   - 紧急公文："特急""加急"

4. **发文机关标志**
   - 字体：小标宋体或黑体，红色
   - 位置：上边缘至版心上边缘 35mm
   - 联合行文：主办机关在前

5. **发文字号**
   - 格式：机关代字〔年份〕序号
   - 示例：国发〔2026〕1号
   - 字体：3号仿宋
   - 位置：居中排布

6. **签发人**（上行文必须标注）
   - 格式："签发人：XXX"
   - "签发人"3号仿宋，姓名3号楷体
   - 位置：发文字号右侧

7. **分隔线**
   - 红色横线，宽度与版心等宽

### 二、主体

1. **标题**
   - 三要素：发文机关名称 + 事由 + 文种
   - 字体：2号方正小标宋简体
   - 位置：红色分隔线下空二行，居中
   - 可分一行或多行排列

2. **主送机关**
   - 位置：标题下空一行，顶格
   - 字体：3号仿宋
   - 回行时仍顶格

3. **正文**
   - 字体：3号仿宋_GB2312
   - 首行缩进2字符
   - 结构层次序号：
     - 第一层："一、"（黑体）
     - 第二层："（一）"（楷体）
     - 第三层："1."（仿宋）
     - 第四层："（1）"（仿宋）

4. **附件说明**
   - 位置：正文下一行，左空二字
   - 格式："附件：1. 标题"

5. **发文机关署名、成文日期和印章**
   - 署名：发文机关全称或规范简称，右空四字
   - 日期：阿拉伯数字，右空四字
   - 印章：端正居中，下压署名和日期

6. **附注**
   - 位置：成文日期下一行，左空二字
   - 格式：圆括号标注
   - 请示件须注明联系人和电话

### 三、版记

1. **版记分隔线**
   - 位置：版记上边缘
   - 黑色横线

2. **抄送机关**
   - 字体：4号仿宋
   - 格式："抄送：XX，XX。"

3. **印发机关和印发日期**
   - 位置：抄送机关下
   - 左标印发机关，右标印发日期
   - 字体：4号仿宋

## 特殊格式要求

### 联合行文
- 标注主办机关发文字号
- 发文机关标志可单独用主办机关或联合标注
- 签发人按发文机关排列顺序依次标注

### 信函格式
- 发文机关标志上边缘距上页边37mm
- 首页不显示页码
- 版记不加分隔线

### 命令(令)格式
- 标题由发文机关 + "命令(令)"组成
- 标题下标注令号
- 正文后标签发人签名、成文日期
